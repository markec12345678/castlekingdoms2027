## 📢 Reddit r/stronghold

**Title:** Stronghold 2027 - Open source remake with modern graphics, modding API, and Slovenian translation (alpha v0.7.0)

**Body:**

Zdravo Stronghold skupnost!

Predstavljam vam **Stronghold 2027** - fork odprtokodnega Stone Kingdoms projekta, ki ga razvijava z namenom moderne izkušnje klasike iz 2001. Ciljno leto izida je 2027.

### Kaj je novo v 0.7.0-alpha?

🎮 **Modding API (alpha)** - Ustvarjaj lastne mode z:
- Lifecycle hook-i (onLoad, onTick, onUnload)
- Event hook-i (onBuildingPlaced, onUnitRecruited)
- Dependency sistem za med-mod odvisnosti
- Sandboxed environment za varnost

✨ **HD Shaderji** - Moderni post-processing:
- Bloom (glow okoli svetlih območij)
- Color grading (cinematic barvna grading)
- Vignette (subtle zatemnitev robov)
- Dynamic lighting (day/night cycle)
- 4 preset-i: cinematic, realistic, vibrant, minimal

📊 **Performance Profiler** - Debug overlay (F3/F4):
- FPS, memory usage, custom counters
- Section timing za optimizacijo
- Dump v datoteko za analizo

🌍 **10 podprtih jezikov**:
- Slovenščina (NOVO - popoln prevod, 472 vrstic)
- Srbščina, Grščina, Bolgarščina (NOVO - delni prevodi)
- Makedonščina, Litovščina, Latvijščina (NOVO - delni prevodi)
- Plus obstoječi: angleščina, nemščina, francoščina, italijanščina, poljščina, portugalščina, ruščina, ukrajinščina, madžarščina

⚔️ **Combat sistem (v razvoju)**:
- CombatController z damage calculation
- ProjectileController za puščice in oblegovalne napade
- AIController z 3 osebnostmi (aggressive, defensive, balanced)
- HealthBarController z barvnimi indikatorji

### Tehnične podrobnosti

- **Engine:** LÖVE 11.5 (Lua)
- **Licenca:** Apache 2.0 (dovoljuje komercialno uporabo)
- **Repozitorij:** [github.com/markec12345678/stronghold2027](https://github.com/markec12345678/stronghold2027)
- **CI/CD:** GitHub Actions z 343 test checks (100% pass)
- **Statistika:** 213,215 vrstic kode, 280 Lua datotek, 71 zgradb, 42 enot
