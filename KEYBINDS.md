# Castle Kingdoms 2027 — Keybind Reference

Popoln seznam vseh tipkovnih bližnjic (v3.12.149). Vse bližnjice so prikazane tudi v igri s F1.

---

## OSNOVNO

| Tipka | Funkcija |
|-------|----------|
| ESC | Pavza / Zapri meni / Zapri panel |
| F1 | Pomoč (to okno z vsemi bližnjicami + iskanje) |

| Space | Pavza / nadaljuj igro (v3.12.139) |
| 1 / 2 / 3 / 4 | Hitrost igre: 1x / 2x / 3x / 5x (v3.12.139) |

| V | Nastavitve (game feel) |
| N | Toast zgodovina — vsa pretekla obvestila (v3.12.127) |
| Ctrl+A | Dosežki — stari loveframes achievement gallery |
| ` + Shift | Odpri konzolo |
| Shift+R | Ponastavi vse nastavitve (zbriše 16 persisted datotek, zahteva restart) |
| Ctrl+Shift+A | Dosežki — modern achievement panel z animacijami (v3.12.128) |
| Ctrl+Shift+I | Statistika — pregled, proizvodnja, trg, lestvice, boj z grafi (v3.12.129) |
| Ctrl+Shift+O | Tutorial manager — vsi hinti z reset/toggle funkcijami (v3.12.132) |

| Ctrl+Shift+J | Barvna tema — ciklaj 6 tem (zlato/moder/zelen/rdeč/temen/vijoličen) (v3.12.146) |
| Ctrl+Shift+L | Dnevnik dogodkov — vsi game events z filtriranjem (v3.12.147) |
| Ctrl+Space | Command Palette — hitri iskalni meni za vse funkcije (v3.12.149) |

## CTRL+R PANEL (Royal Systems)

| Tipka | Funkcija |
|-------|----------|
| / (slash) | Iskanje sistemov po imenu |
| ← → / A D | Prejšnja/naslednja stran |
| ↑ ↓ / W S | Navigacija med sistemi |
| Home / End | Skok na prvo/zadnjo stran |
| PgUp / PgDn | Hitra navigacija med stranmi |
| Wheel | Scroll med stranmi (miška) |
| Tab | Ciklaj kategorije (Steklar/Livar/Knigovez/...) |
| F | Ciklaj sortiranje (5 načinov: alpha/buildings/products/gold/active) |

## CTRL+SHIFT+G PANEL (Tech Tree)

| Tipka | Funkcija |
|-------|----------|
| G | Preklopi pogled: graf vozlišč ↔ tekstovno drevo |
| / (slash) | Odpri iskanje — tipkaj za filtriranje po imenu |
| Enter | Potrdi iskanje (filter ostane aktiven) |
| Backspace | Briši zadnji znak iskanja |
| Click | Klik na vozlišče: fokusira sorodne (poudari, druga zatemni) |
| Shift+Click | Dodaj/odstrani vozlišče iz multi-izbire (primerjaj več sistemov) |
| C | Počisti multi-izbiro in fokus |
| 2x Click | Dvaklik na vozlišče: odpri Royal Systems Panel (Ctrl+R) in skoči na sistem |
| T | Preklopi pot: direktno (1 stopnja) ↔ celotna pot (transitivno) |
| M | Skrij/prikaži minimap (pregledni graf v kotu, click za skok) |
| D | Skrij/prikaži indikator globine (barvni krožec z številko plasti) |
| A | Skrij/prikaži puščice smeri na povezavah (base → dependent) |
| S | Preklopi sortiranje verig: abecedno ↔ po globini (plitev→globok) |
| L | Ciklaj filter stanja: vsi → aktivni → razpoložljivi → zaklenjeni |
| Tab | Naslednje vozlišče (keyboard navigacija, auto-scroll + fokus) |
| Shift+Tab | Prejšnje vozlišče (keyboard navigacija nazaj) |
| B | Dodaj/odstrani zaznamek (★) na hovered/selected vozlišču |
| Shift+B | Preklopi filter: prikaži samo zaznamovana vozlišča |
| E | Izvozi konfiguracijo (filtri, sort, focus, bookmarks) v odložišče |
| Shift+E | Uvozi konfiguracijo iz odložišča |
| P | Ciklaj preset (Vsi → Aktivni → Razpoložljivi → Zaklenjeni → Zaznamovani → Custom...) |
| Shift+P | Shrani trenutno konfiguracijo kot custom preset (persisted) |
| Shift+X | Izbriši trenutno izbran custom preset (built-in ni mogoče brisati) |
| F | Počisti fokus (ali klik ponovno na isto vozlišče) |
| Hover | V graf pogledu: prikaži podrobnosti odvisnosti + število odvisnikov |
| ↑ ↓ | Scroll po verigah |
| PgUp / PgDn | Hitri scroll (150px) |
| Home | Skok na vrh |
| Wheel | Scroll (miška) |
| ESC | Počisti iskanje → fokus → zapri panel (zaporedno) |

## Debug Console

| Tipka | Funkcija |
|-------|----------|

### Console Commands

| Command | Description |
|---------|-------------|
| help | List all commands |
| clear | Clear console output |
| stats | Show game statistics |
| perf | Show FPS, quality, memory |
| mods | List loaded mods |
| reload <mod_id> | Reload a mod |
| time <0-1> | Set time of day |
| gold <amount> | Add gold |
| spawn <type> | Spawn siege weapon |
| checklist | Run release checklist |
| gc | Force garbage collection |
| profile <name> | Apply graphics profile |
