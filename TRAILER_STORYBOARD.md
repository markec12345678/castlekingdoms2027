## Tehnične zahteve

### Format
- **Resolucija:** 1920×1080 (1080p) ali 3840×2160 (4K)
- **FPS:** 60
- **Format:** MP4 (H.264)
- **Trajanje:** 90 sekund

### Potrebno za snemanje
1. **HD grafika** - trenutno manjkajo ( potrebuje grafičnega oblikovalca)
2. **Screen recording** - LÖVE v windowed mode + OBS
3. **Video editing** - DaVinci Resolve / Premiere Pro
4. **Glasba** - epic medieval soundtrack
5. **Voice acting** - slovenščina za Sir Markus (opcijsko)

### Kaj posneti iz igre
| Scena | Kako |
|-------|------|
| Gradnja | Zaženi igro, postavi zgradbe, snemaj |
| Market UI | Pritisni M, snemaj |
| Karavana | Pritisni C, pošlji karavano |
| Combat | Pritisni F8 (combat test), snemaj |
| Siege | Naloži Mission 7 ali 10 |
| Vreme | Pritisni F5 (snow/storm) |
| Dan/noč | Pritisni F6 (night) |
| Settings | Pritisni V |

### Glasba za trailer
- **Intro:** Tiho, ambientalno (veter + ptice)
- **Gradnja:** Upadajoča, optimistična
- **Vojska:** Napetost, ritmični bobni
- **Obleganje:** Epična, polna orkestracija
- **Finale:** Zborična, triumfalna

## Nasveti za dober trailer

1. **Pokaži gameplay, ne samo cutscene** - igralci želijo videti mehanike
2. **Screen shake je viden** - pokaže game feel
3. **Dinamične cene so viden** - unikatna feature
4. **AI defense response** - pokaži AI ki brani
5. **Slovenski prevod** - pokaži da je v slovenščini (unutarnji trg)
6. **Modding API** - omeni v text overlay
7. **Call to action:** "Wishlist na Steam"
