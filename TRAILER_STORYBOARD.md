# Stronghold 2027 — Trailer Storyboard

## Trailer Duration: 60 seconds

### Scene 1: Opening (0-5s)
- **Visual**: Black screen → fade in to Fernhaven map from above
- **Audio**: Dramatic horn sound, ambient medieval music starts
- **Text**: "Leto 1147. Kraljestvo Valdemar je v kaosu."
- **Action**: Camera slowly pans across the landscape

### Scene 2: Building (5-15s)
- **Visual**: Player places WoodenKeep → buildings spring up (sped up)
- **Audio**: Hammer sounds, wood creaking, cheerful music
- **Text**: "Zgradi svoje kraljestvo."
- **Action**: Show building queue (shift+click), rally points, auto-workers
- **Highlight**: HD pipeline on — normal mapping, bloom, SSAO visible

### Scene 3: Economy (15-25s)
- **Visual**: Farms producing food, market trading, resource flow visualizer ON
- **Audio**: Coins clinking, market ambience
- **Text**: "Upravljaj gospodarstvo."
- **Action**: Dynamic market prices changing, trade caravan arriving
- **Highlight**: Weather changes to rain — farms boost 50%

### Scene 4: Military (25-35s)
- **Visual**: Barracks training units, formations changing (line → wedge → box)
- **Audio**: Military drums, sword sharpening
- **Text**: "Usposobi vojsko."
- **Action**: Units gain veterancy (stars appear), formation bonuses visible
- **Highlight**: 5 formation types cycling

### Scene 5: Combat (35-45s)
- **Visual**: Epic battle — arrows flying, siege weapons firing, screen shake
- **Audio**: Combat music kicks in (dynamic music transition), battle sounds
- **Text**: "Bori se za prevlado."
- **Action**: Catapult fires → building collapses, units charge
- **Highlight**: Particle effects (blood, sparks, dust), death animations

### Scene 6: Multiplayer (45-52s)
- **Visual**: Split screen — 2 players building simultaneously, diplomacy panel
- **Audio**: Upbeat music, chat notification sounds
- **Text**: "Igraj s prijatelji."
- **Action**: Alliance formed, trade completed, chat messages
- **Highlight**: 8-player multiplayer, co-op campaign

### Scene 7: Features montage (52-57s)
- **Visual**: Rapid cuts — map editor, replay, achievements, weather, day/night
- **Audio**: Fast-paced music, sound effects per cut
- **Text**: "32 jezikov. 20 misij. Neskončne možnosti."
- **Action**: 
  - Cut 1: Map editor painting terrain (F12)
  - Cut 2: Achievement unlocked notification
  - Cut 3: Day → night transition
  - Cut 4: Fog → snow → storm weather cycle
  - Cut 5: Skirmish trail mission select
  - Cut 6: Debug console typing
  - Cut 7: Statistics dashboard
  - Cut 8: Credits scrolling

### Scene 8: Closing (57-60s)
- **Visual**: Logo appears — "STRONGHOLD 2027" on dark background
- **Audio**: Music crescendo → silence
- **Text**: "Prihaja kmalu na Steam."
- **Action**: Steam logo appears, "Wishlist now" button

## Recording Instructions

### Equipment
- Recording software: OBS Studio (free)
- Resolution: 1920×1080 (1080p) or 3840×2160 (4K)
- FPS: 60
- Format: MP4 (H.264)

### Settings for best visuals
1. Set quality to Ultra (Ctrl+O → Graphics → Ultra)
2. Enable HD pipeline (F7)
3. Set time to day (F6)
4. Weather: clear (F5)
5. Resource flow OFF (Ctrl+Y)
6. Minimap visible

### Recording tips
- Use replay system (Ctrl+R) to record perfect moments
- Use screenshot manager (Ctrl+M) for key frames
- Record combat at 0.5x speed for dramatic effect
- Use spectator mode (Ctrl+Shift+S) for cinematic angles

### Key moments to capture
1. **Building placement** — show construction animation
2. **Unit training** — show rally point flow
3. **Formation change** — show all 5 formations
4. **Siege weapon fire** — catapult + trebuchet
5. **Victory** — EndGameScreen with stats
6. **Multiplayer** — diplomacy + trade + chat
7. **Weather change** — all 6 types
8. **Day/night** — full cycle
9. **Map editor** — terrain painting
10. **Achievements** — unlock notification
