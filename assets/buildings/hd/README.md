HD Building Sprites (256x256)

Place HD building sprites here. Naming convention: <BuildingName>.png

Key buildings (50 supported):
- Keep.png, Stockpile.png, Granary.png, Barracks.png, Market.png
- Armoury.png, Inn.png, Cathedral.png, Church.png, Chapel.png
- Blacksmith.png, Bakery.png, Brewery.png, Fletcher.png, Quarry.png
- Mine.png, House.png, Residence.png, Stable.png, Fortress.png
- RoundTower.png, SquareTower.png, DefenseTower.png, StoneWall.png
- StoneGate.png, StoneGateBig.png, etc.

Files placed here OVERRIDE the original building sprites when HD is enabled.
Toggle HD buildings via Command Palette (Ctrl+Space > 'HD buildings').

Format requirements:
- 256x256 pixels (or 512x512 for large buildings like Cathedral, Fortress)
- PNG with alpha channel
- Isometric perspective (matching existing Stone Kingdoms style)
- Hand-painted medieval look
