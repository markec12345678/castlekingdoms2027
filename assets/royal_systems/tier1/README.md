This folder contains hand-crafted 256x256 PNG sprites for Royal systems.

Naming convention: <SystemBaseName>.png
For example: RoyalAbacusMakerSystem -> Abacus.png

Files placed here OVERRIDE the procedural icons generated by royal_icon_generator.lua

See ASSET_PRIORITY_PLAN.md for the priority list of which systems to sprite first.
See HD_SPRITE_GUIDE.md (created in v3.12.155) for technical specifications.

Format requirements:
- 256x256 pixels
- PNG with alpha channel
- Top-down medieval style
- Compatible with Stone Kingdoms aesthetic
