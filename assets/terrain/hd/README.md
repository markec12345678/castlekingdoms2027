HD Terrain Textures (256x256)

Place HD terrain textures here. Naming convention: <biome>.png

Supported biomes (from terrain.lua _G.terrainBiome):
- abundant_grass.png
- dirt.png
- scarce_grass.png
- yellow_grass.png
- orange_grass.png
- pitch_grass.png
- mountain_grass_b.png
- beach.png
- sea_deep.png
- sea_beach.png
- sea_walkable.png
- land_stones_1_white_rock.png

Files placed here OVERRIDE the original tileset when HD terrain is enabled.
Toggle HD terrain with F7 (existing HD render pipeline) or via Command Palette.

Format requirements:
- 256x256 pixels (4x original 64x64)
- PNG with alpha channel (for sea/water edges)
- Top-down medieval style
- Seamless tiling (edges must match)
